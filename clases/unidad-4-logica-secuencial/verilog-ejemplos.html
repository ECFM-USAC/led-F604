De Verilog a circuito

Los circuitos combinacionales de la Unidad 3 se pueden describir en Verilog con asignaciones continuas (assign). Una herramienta de síntesis lee el código y deduce el circuito de compuertas equivalente.

Las simulaciones de esta página se generaron así: el código de cada ejemplo se sintetizó con Yosys y se dibuja con DigitalJS. En cada simulación:

  • Haz clic en los botones de entrada para cambiar entre 0 y 1; en las entradas de varios bits escribe el número.
  • Las líneas cambian de color según el valor lógico que transportan, y las lámparas de salida se encienden con 1.
  • Puedes arrastrar los componentes para reacomodar el circuito.

Para probar tu propio código, pégalo en DigitalJS Online y presiona el botón de sintetizar (Synthesize and simulate!).

Ejemplo 1: sumador completo

El sumador completo suma tres bits (a, b y el acarreo de entrada cin) y produce la suma S y el acarreo de salida Cout. En la clase 8 se simplificaron con XOR:

S = a ⊕ b ⊕ cin

Cout = a·b + cin·(a ⊕ b)

module sumador_completo (
    input  a, b, cin,
    output s, cout
);
    assign s    = a ^ b ^ cin;
    assign cout = (a & b) | (cin & (a ^ b));
endmodule

Ejemplo 2: sumador-restador de 4 bits

Es el circuito de la clase 9: cuatro sumadores completos con una XOR en cada bit de B controlada por M.

  • M = 0: B ⊕ 0 = B y c0 = 0, el circuito calcula A + B.
  • M = 1: B ⊕ 1 = B' y c0 = 1, el circuito calcula A + B' + 1 = A − B (complemento a dos).
  • V = c3 ⊕ c4 indica desbordamiento cuando A y B se interpretan con signo.
module sumador_completo (          // el módulo del ejemplo 1
    input  a, b, cin,
    output s, cout
);
    assign s    = a ^ b ^ cin;
    assign cout = (a & b) | (cin & (a ^ b));
endmodule

module sumador_restador (
    input  [3:0] A, B,
    input        M,                  // 0: A + B   1: A - B
    output [3:0] S,
    output       C, V
);
    wire [3:0] Bx = B ^ {4{M}};      // complemento a uno de B cuando M = 1
    wire c1, c2, c3, c4;

    // cuatro sumadores completos en cascada; M entra como acarreo inicial
    sumador_completo fa0 (.a(A[0]), .b(Bx[0]), .cin(M),  .s(S[0]), .cout(c1));
    sumador_completo fa1 (.a(A[1]), .b(Bx[1]), .cin(c1), .s(S[1]), .cout(c2));
    sumador_completo fa2 (.a(A[2]), .b(Bx[2]), .cin(c2), .s(S[2]), .cout(c3));
    sumador_completo fa3 (.a(A[3]), .b(Bx[3]), .cin(c3), .s(S[3]), .cout(c4));

    assign C = c4;
    assign V = c3 ^ c4;
endmodule
  • Instanciación: sumador_completo fa0 (...) coloca una copia del módulo del ejemplo 1 llamada fa0; .a(A[0]) conecta su puerto a con el bit A[0]. Así se construyen circuitos grandes a partir de bloques probados.
  • {4{M}} repite M cuatro veces (MMMM), así que B ^ {4{M}} son las cuatro XOR del diagrama de la clase 9.

En la simulación cada bloque sumador_completo se puede abrir con doble clic para ver sus compuertas.

Ejemplo 3: multiplexor de 4 a 1

El multiplexor de la clase 11a envía a la salida Y una de las cuatro entradas I0–I3, según las líneas de selección S1S0. Se puede describir de dos formas equivalentes:

Con la expresión booleana

Un término AND por cada combinación de S1S0, igual que el diagrama de compuertas.

module mux4a1 (
    input  i0, i1, i2, i3,
    input  s1, s0,
    output y
);
    assign y = (~s1 & ~s0 & i0) |
               (~s1 &  s0 & i1) |
               ( s1 & ~s0 & i2) |
               ( s1 &  s0 & i3);
endmodule

Con el operador condicional

s ? a : b vale a si s = 1 y b si s = 0: es un multiplexor de 2 a 1.

module mux4a1 (
    input  i0, i1, i2, i3,
    input  s1, s0,
    output y
);
    assign y = s1 ? (s0 ? i3 : i2)
                  : (s0 ? i1 : i0);
endmodule

Valores de prueba:

S1S0Y

01I1

11I3

Ejemplo 4: codificador con prioridad de 4 a 2

El codificador con prioridad de la clase 10 entrega en xy el número de la entrada activa de mayor índice (D3 tiene la prioridad más alta). V = 1 indica que al menos una entrada está activa. Del mapa de Karnaugh:

x = D2 + D3

y = D3 + D1·D2'

V = D0 + D1 + D2 + D3

module codificador_prioridad (
    input  d0, d1, d2, d3,
    output x, y, v
);
    assign x = d2 | d3;
    assign y = d3 | (d1 & ~d2);
    assign v = d0 | d1 | d2 | d3;
endmodule

Valores de prueba:

D0D1D2D3xyV
0000000
1000001
1100011
0110101
1111111

Con todas las entradas en 0, la tabla de la clase 10 marca x y y como indiferentes (X). Con estas ecuaciones el circuito entrega x = y = 0; por eso hay que revisar V antes de usar xy.
