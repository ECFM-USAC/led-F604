Verilog para circuitos secuenciales

En los ejemplos combinacionales cada salida se describió con assign: la salida cambia en cuanto cambian las entradas. Un circuito secuencial, en cambio, guarda un estado que solo cambia en el flanco del reloj. En Verilog eso se describe con un bloque always:

ConstrucciónSignificado
output reg qq guarda un valor entre flancos de reloj (será un flip-flop)
always @(posedge clk)el bloque se ejecuta en cada flanco de subida de clk
always @(negedge clk)el bloque se ejecuta en cada flanco de bajada de clk
always @(posedge clk or negedge clr_n)además reacciona cuando clr_n baja: borrado asíncrono
q <= d;asignación no bloqueante: todos los flip-flops toman su nuevo valor al mismo tiempo, con los valores que había antes del flanco

En las simulaciones:

  • La entrada clk es un reloj que oscila solo.
  • clr_n es el borrado activo en 0 (CLR'). Empieza en 0, así que el circuito arranca borrado: haz clic en clr_n para ponerlo en 1 y que el circuito empiece a funcionar.
  • Debajo de cada circuito se dibuja el diagrama de tiempos de sus señales principales.

Ejemplo 5: flip-flop D con borrado asíncrono

Es el flip-flop D de la clase 13: en cada flanco de subida copia D en Q, con la ecuación característica Q(t+1) = D. Entre flancos, Q no cambia aunque D cambie.

module flipflop_d (
    input      clk,
    input      clr_n,          // borrado asíncrono, activo en 0
    input      d,
    output reg q
);
    always @(posedge clk or negedge clr_n)
        if (!clr_n) q <= 1'b0;   // CLR' = 0: Q se borra sin esperar al reloj
        else        q <= d;      // en cada flanco de subida: Q(t+1) = D
endmodule

Ejemplo 6: contador asíncrono de 2 bits

Es el Ejemplo 1 de la clase 15: dos flip-flops T con T = 1. FF0 recibe CLK y FF1 recibe Q0 como reloj, por eso cada flip-flop está en su propio bloque always, con un evento de reloj distinto.

module contador_asincrono (
    input      clk,
    input      clr_n,          // borrado asíncrono, activo en 0
    output reg q0, q1
);
    // FF0: T0 = 1, se dispara con el flanco de bajada de CLK
    always @(negedge clk or negedge clr_n)
        if (!clr_n) q0 <= 1'b0;
        else        q0 <= ~q0;

    // FF1: T1 = 1, su reloj es Q0 (flanco de bajada de Q0)
    always @(negedge q0 or negedge clr_n)
        if (!clr_n) q1 <= 1'b0;
        else        q1 <= ~q1;
endmodule

Ejemplo 7: contador síncrono de 2 bits

Es la versión sincrónica equivalente de la clase 15: los dos flip-flops comparten CLK y la condición “Q0 = 1” pasa a la entrada T1. Las líneas del bloque son directamente las ecuaciones de estado.

module contador_sincrono (
    input      clk,
    input      clr_n,          // borrado asíncrono, activo en 0
    output reg q0, q1
);
    // los dos flip-flops comparten el mismo reloj
    always @(negedge clk or negedge clr_n)
        if (!clr_n) begin
            q0 <= 1'b0;
            q1 <= 1'b0;
        end else begin
            q0 <= q0 ^ 1'b1;     // T0 = 1:  Q0(t+1) = Q0 ⊕ 1 = Q0'
            q1 <= q1 ^ q0;       // T1 = Q0: Q1(t+1) = Q1 ⊕ Q0
        end
endmodule

Gracias a la asignación no bloqueante (<=), q1 <= q1 ^ q0 usa el valor de q0 antes del flanco, aunque la línea anterior lo esté cambiando. Así se comportan los flip-flops reales: todos leen sus entradas antes del flanco y cambian juntos.

En un circuito físico, en el contador asíncrono Q1 cambia un retardo de propagación (tpd) después de Q0, y ese retardo se acumula con cada bit (ver la clase 15). El simulador usa retardos casi nulos, por eso en los dos diagramas de tiempos parecen cambiar al mismo tiempo.

Ejemplo 8: registro de desplazamiento de 4 bits

Es el registro de desplazamiento de la clase 14: en cada flanco de reloj todos los bits se mueven una posición a la derecha, el bit de la entrada serie SI entra por la izquierda (bit 3) y el bit 0 sale por SO.

module registro_desplazamiento (
    input            clk,
    input            clr_n,    // borrado asíncrono, activo en 0
    input            si,       // entrada serie
    output reg [3:0] q,
    output           so        // salida serie
);
    always @(posedge clk or negedge clr_n)
        if (!clr_n) q <= 4'b0000;
        else        q <= {si, q[3:1]};   // desplaza a la derecha; SI entra por el bit 3

    assign so = q[0];
endmodule

{si, q[3:1]} concatena SI con los bits 3, 2 y 1 de q, formando el nuevo valor de 4 bits. Los cuatro flip-flops se describen con un solo reg [3:0].
