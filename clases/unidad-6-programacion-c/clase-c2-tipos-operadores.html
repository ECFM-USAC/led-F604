Variables: declarar antes de usar

Una variable es un nombre para un espacio de memoria donde se guarda un valor. En C, toda variable debe declararse con su tipo antes de usarse; el tipo le dice al compilador cuántos bytes reservar y cómo interpretar esos bytes.

int lower, upper, step;      /* tres enteros, sin valor inicial  */
float fahr, celsius;         /* dos numeros con decimales        */
int bits = 8;                /* declaracion con inicializacion   */

Los nombres pueden llevar letras, dígitos y guion bajo, no pueden empezar con un dígito y distinguen mayúsculas de minúsculas: Suma, suma y SUMA son tres variables distintas. No se pueden usar las palabras reservadas del lenguaje (int, if, while, return, ...).

Una variable declarada y no inicializada no vale cero: contiene lo que hubiera en esa posición de memoria. Leerla antes de asignarle algo es uno de los errores más difíciles de encontrar en C, porque el programa puede funcionar hoy y fallar mañana. Compilando con -Wall el compilador avisa: 'x' is used uninitialized.

Tipos enteros y cuántos bits ocupan

C ofrece varios tipos enteros que se diferencian en el número de bits y en si admiten signo. El estándar fija mínimos, no tamaños exactos: los valores de la tabla son los típicos en una PC de 64 bits con Linux.

TipoBits típicosRangoPara qué se usa
char8−128 a 127Un carácter o un byte de datos
unsigned char80 a 255Un byte «crudo»: el estado de 8 líneas de un bus
short16−32 768 a 32 767Enteros pequeños con signo
int32±2 147 483 647El tipo entero por omisión
long64±9,2×10¹⁸Contadores grandes
unsigned int320 a 4 294 967 295Cuando el valor nunca es negativo

El rango sale directamente de la Unidad 1: con n bits sin signo se representan 2ⁿ valores, de 0 a 2ⁿ−1; con signo, en complemento a dos, de −2ⁿ⁻¹ a 2ⁿ⁻¹−1. unsigned char es, literalmente, el registro de 8 bits del que hablamos en la Unidad 4.

El operador sizeof da el tamaño en bytes de un tipo o variable en la máquina donde se compila:

/* tamanos.c -- cuantos bytes ocupa cada tipo */
#include <stdio.h>

int main(void)
{
    printf("char        : %zu byte(s)\n", sizeof(char));
    printf("short       : %zu byte(s)\n", sizeof(short));
    printf("int         : %zu byte(s)\n", sizeof(int));
    printf("long        : %zu byte(s)\n", sizeof(long));
    printf("float       : %zu byte(s)\n", sizeof(float));
    printf("double      : %zu byte(s)\n", sizeof(double));
    printf("un int tiene %zu bits\n", sizeof(int) * 8);
    return 0;
}

Si necesita un tamaño garantizado —por ejemplo, modelar un registro de exactamente 8 o 16 bits— incluya <stdint.h> y use uint8_t, uint16_t, uint32_t. Es la práctica normal en firmware, donde el ancho del dato debe coincidir con el del hardware.

Punto flotante: float y double

Para valores con parte decimal, C ofrece float (32 bits, unas 7 cifras significativas) y double (64 bits, unas 15). Use double salvo que tenga una razón para no hacerlo: es el tipo por omisión de los literales y de las funciones de math.h.

float  v1 = 3.14f;      /* la f final lo hace literal float */
double v2 = 3.141592653589793;
double e  = 1.6e-19;    /* notacion cientifica: 1.6 x 10^-19 */

El punto flotante es una aproximación binaria: 0.1 + 0.2 no da exactamente 0.3. De ahí una regla que volverá en la clase de condicionales: nunca compare dos flotantes con ==; compare la diferencia absoluta contra una tolerancia.

Constantes: literales, #define y const

Un número escrito directamente en el código es un literal. C reconoce varias bases, lo cual es cómodo cuando se trabaja con bits:

LiteralBase / tipoObservación
202decimalbase 10, el caso normal
0xCAhexadecimalprefijo 0x; cada dígito son 4 bits
0312octalprefijo 0; cuidado: 012 no es 12
'A'caráctervale 65, su código ASCII
3.5punto flotantees double; 3.5f es float

Escribir números «mágicos» repartidos por el programa es mala práctica. Hay dos formas de darles nombre:

#define (preprocesador)

#define LOWER   0
#define UPPER 300
#define STEP   20

Sustitución de texto antes de compilar. Por convención va en MAYÚSCULAS y no lleva punto y coma ni signo =.

const (lenguaje)

const int LOWER = 0;
const int UPPER = 300;

Es una variable real que el compilador protege contra escritura. Tiene tipo, y por eso el compilador puede verificarla mejor.

Ambas se usan en la práctica. #define domina en código heredado y en firmware; const es preferible cuando el valor tiene un tipo claro. Lo importante es que el 300 no aparezca disperso en diez líneas distintas.

Operadores aritméticos y la trampa de la división entera

Los cinco operadores aritméticos son +, -, *, / y % (módulo o residuo). El módulo solo se aplica a enteros.

int a = 17, b = 5;

a + b    /*  22 */
a - b    /*  12 */
a * b    /*  85 */
a / b    /*   3   <-- division ENTERA: se trunca, no se redondea */
a % b    /*   2   <-- lo que sobra */

Que 17 / 5 valga 3 no es un error del lenguaje: cuando ambos operandos son enteros, la división es entera. El problema aparece cuando no se espera:

Mal

celsius = 5 / 9 * (fahr - 32);

5 / 9 se evalúa primero y vale 0. Todo el resultado es 0, para cualquier temperatura.

Bien

celsius = 5.0 / 9.0 * (fahr - 32.0);

Con al menos un operando flotante, la división es flotante y el resultado es correcto.

Lejos de ser un estorbo, / y % sobre enteros son la herramienta exacta para la conversión a binario que se estudió en la Unidad 1: n % 2 da el bit menos significativo y n / 2 desplaza el número una posición a la derecha. Ese es el algoritmo de divisiones sucesivas, escrito en dos operadores.

Verdadero y falso en C

C no tuvo un tipo booleano hasta C99, y aun hoy el convenio sigue siendo el original:

Falso

El valor 0, y nada más.

Verdadero

Cualquier valor distinto de 0: 1, −7, 3.5 o un puntero no nulo.

Los operadores relacionales comparan y producen un entero: 1 si la relación se cumple, 0 si no.

OperadorSignificadoEjemplo
==igual aa == b
!=distinto dea != b
<   <=menor que, menor o igualfahr <= 300
>   >=mayor que, mayor o igualn > 0

Los operadores lógicos combinan condiciones completas: && (AND), || (OR) y ! (NOT). Tienen una propiedad importante llamada evaluación de cortocircuito: se evalúan de izquierda a derecha y se detienen apenas el resultado está decidido.

if (n != 0 && 100 / n > 5)   /* si n es 0, la division NUNCA se evalua */
if (listo || calcular())     /* si listo es verdadero, calcular() no se llama */

Si prefiere escribir true y false, incluya <stdbool.h> y use el tipo bool. Por debajo sigue siendo un entero.

El error clásico de C: escribir = (asignación) donde va == (comparación). if (x = 0) asigna 0 a x y la condición resulta falsa siempre; el compilador lo acepta. Con -Wall aparece como suggest parentheses around assignment used as truth value.

Operadores a nivel de bits: las compuertas dentro del procesador

Aquí C se encuentra con el resto del curso. Mientras && y || trabajan con la condición completa, los operadores a nivel de bits aplican la compuerta a cada par de bits de los operandos, en paralelo, exactamente como lo haría un arreglo de compuertas en hardware.

OperadorOperaciónEjemploUso típico
&AND bit a bit0xCA & 0x0F = 0x0AAislar bits (enmascarar)
|OR bit a bit0xC0 | 0x0A = 0xCAEncender bits
^XOR bit a bit0xCA ^ 0xFF = 0x35Invertir bits seleccionados; detectar diferencias
~NOT bit a bit~0x0F = 0xFFFFFFF0Complemento a uno de todos los bits
<<desplazar a la izquierda1 << 3 = 8Multiplicar por 2ⁿ; construir máscaras
>>desplazar a la derecha0xCA >> 4 = 0x0CDividir entre 2ⁿ; extraer el bit n

Visto bit a bit, 0xCA & 0x0F es el mismo dibujo de la Unidad 3:

   1100 1010      (0xCA)
 & 0000 1111      (0x0F = mascara del nibble bajo)
   ---------
   0000 1010      (0x0A)

La distinción entre lógico y bit a bit es la fuente de confusión más común al empezar:

! — NOT lógico

int a = 1;
!a      /* vale 0 */
!0      /* vale 1 */

Convierte cualquier valor a 0 o 1 y lo invierte. Es el que se usa en condiciones.

~ — NOT bit a bit

int a = 1;          /* ...0000 0001 */
~a      /* vale -2:  ...1111 1110 */
~a & 1  /* vale 0: el bit 0 invertido */

Invierte los 32 bits. Para quedarse con un solo bit hay que enmascarar con & 1.

Máscaras: leer, encender y apagar un bit

Tres recetas que se usan todos los días en programación de hardware. En todas, (1 << n) construye una máscara con un único 1 en la posición n.

OperaciónExpresión en CPor qué funciona
Leer el bit n(x >> n) & 1Desplaza el bit hasta la posición 0 y borra el resto
Encender el bit nx |= (1 << n)OR con la máscara: ese bit pasa a 1, los demás no cambian
Apagar el bit nx &= ~(1 << n)AND con la máscara invertida: ese bit pasa a 0
Invertir el bit nx ^= (1 << n)XOR con la máscara: ese bit cambia de estado

Estas cuatro líneas son, por ejemplo, la forma en que un microcontrolador enciende un LED sin alterar los otros siete pines del mismo puerto.

Asignación compuesta, incremento y decremento

C ofrece abreviaturas para la forma «modificar una variable a partir de sí misma». x += 3 es idéntico a x = x + 3, y lo mismo vale para -=, *=, /=, %=, &=, |=, ^=, <<= y >>=.

fahr += STEP;        /* fahr = fahr + STEP        */
mask <<= 1;          /* mask = mask << 1          */
puerto &= ~(1 << 3); /* apaga el bit 3 del puerto */

Sumar o restar uno tiene su propio operador, y aparece en dos formas que no son equivalentes cuando el resultado se usa:

++n — prefijo

Incrementa y luego entrega el valor nuevo.

int n = 5;
int m = ++n;   /* n = 6, m = 6 */

n++ — sufijo

Entrega el valor viejo y luego incrementa.

int n = 5;
int m = n++;   /* n = 6, m = 5 */

Como sentencia aislada —n++; o ++n; en una línea propia— las dos formas hacen exactamente lo mismo. La diferencia importa solo cuando el valor se usa dentro de una expresión mayor.

Conversiones de tipo y casting

Cuando una expresión mezcla tipos, el compilador convierte automáticamente el «menor» al «mayor»: char → int → long → float → double. Por eso 5.0 / 9 funciona: el 9 se convierte a double.

La conversión también ocurre al asignar, y ahí puede perder información sin aviso:

int   n = 3.9;        /* n vale 3: se TRUNCA, no se redondea */
char  c = 300;        /* desbordamiento: no cabe en 8 bits   */
float f = 1 / 2;      /* f vale 0.0: la division fue entera  */

Cuando la conversión es intencional se escribe explícitamente con un cast, poniendo el tipo entre paréntesis:

int aciertos = 7, total = 9;

double razon = aciertos / total;            /* 0.0  -- mal  */
double buena = (double) aciertos / total;   /* 0.777... bien */

El cast se aplica solo al operando que le sigue. En (double) aciertos / total basta con convertir el primero: el segundo se promueve solo.

Salida con printf

printf recibe una cadena de formato y, después, un valor por cada marca % que aparezca en ella. Cada marca indica cómo interpretar e imprimir el valor correspondiente.

MarcaTipo esperadoImprime
%dintentero decimal con signo
%uunsignedentero decimal sin signo
%ldlongentero largo
%fdoublepunto flotante, 6 decimales por omisión
%ccharun carácter
%scadenatexto terminado en '\0'
%x / %ointhexadecimal / octal
%zusize_tel tipo que devuelve sizeof
%%—imprime un signo de porcentaje literal

Entre el % y la letra se puede indicar ancho y precisión, que es lo que permite alinear tablas:

printf("%4d %6.1f\n", fahr, celsius);
/*      |     |
        |     +-- %6.1f : 6 columnas de ancho, 1 decimal
        +-------- %4d   : 4 columnas de ancho, alineado a la derecha */

Si el tipo de la marca no coincide con el del valor, el programa imprime basura o falla. printf("%d", 3.5) es un error que -Wall detecta: format '%d' expects argument of type 'int'.

Entrada con scanf

scanf es la contraparte de printf: lee de la terminal según una cadena de formato. La diferencia crítica es que necesita saber dónde guardar lo leído, y por eso se le pasa la dirección de la variable con el operador &.

/* leer.c -- leer un entero y un numero real */
#include <stdio.h>

int main(void)
{
    int n;
    double x;

    printf("Ingrese un entero: ");
    if (scanf("%d", &n) != 1) {          /* verificar que SI leyo */
        printf("entrada invalida\n");
        return 1;
    }

    printf("Ingrese un real: ");
    scanf("%lf", &x);                    /* ojo: %lf para double  */

    printf("leidos: n = %d, x = %.3f\n", n, x);
    return 0;
}

Tres detalles que causan problemas a todo el mundo la primera vez:

  • Olvidar el &. scanf("%d", n) compila con advertencia y provoca una falla de segmentación. El & es obligatorio para variables simples (no para arreglos ni cadenas, como se verá más adelante).
  • Las marcas no son iguales que en printf. Para double se usa %lf al leer, aunque se imprima con %f.
  • scanf devuelve cuántos valores logró leer. Ignorar ese valor es asumir que el usuario siempre teclea lo que se le pide.

scanf deja el salto de línea pendiente en la entrada, lo que estorba al mezclarlo con lectura de caracteres o de líneas. En la clase de arreglos y cadenas se verá fgets, que es la forma robusta de leer texto.

Ejemplo integrador: compuertas y bits de un número

El programa lee un valor de 0 a 15, lo descompone en sus cuatro bits con desplazamientos y máscaras, y aplica las compuertas básicas a los dos bits menos significativos.

/* bits.c -- descomponer un numero en bits y aplicar compuertas */
#include <stdio.h>

int main(void)
{
    int n;

    printf("Ingrese un valor de 0 a 15: ");
    if (scanf("%d", &n) != 1 || n < 0 || n > 15) {
        printf("valor fuera de rango\n");
        return 1;
    }

    int b3 = (n >> 3) & 1;
    int b2 = (n >> 2) & 1;
    int b1 = (n >> 1) & 1;
    int b0 = (n >> 0) & 1;

    printf("\n%2d decimal = %d%d%d%d binario = 0x%X hex\n", n, b3, b2, b1, b0, n);

    printf("\nCompuertas aplicadas a b1 = %d y b0 = %d:\n", b1, b0);
    printf("  AND : %d\n", b1 & b0);
    printf("  OR  : %d\n", b1 | b0);
    printf("  XOR : %d\n", b1 ^ b0);
    printf("  NOT b0 : %d\n", !b0);

    return 0;
}

Una corrida de ejemplo:

$ ./bits
Ingrese un valor de 0 a 15: 10

10 decimal = 1010 binario = 0xA hex

Compuertas aplicadas a b1 = 1 y b0 = 0:
  AND : 0
  OR  : 1
  XOR : 1
  NOT b0 : 1

El programa repite cuatro veces la misma línea para extraer los bits. Esa repetición es exactamente lo que un bucle elimina: en la clase de estructuras de bucle el mismo programa funcionará para cualquier número de bits con tres líneas de código.

Ejercicios propuestos

  1. Compile y ejecute tamanos.c. Compare el resultado con la tabla de la clase y calcule, a partir de los bytes reportados, el rango de short y de unsigned short en su máquina.
  2. Escriba un programa que lea una temperatura en Fahrenheit y muestre su equivalente en Celsius con un decimal. Escríbalo primero con 5/9 y observe el resultado erróneo; corríjalo después.
  3. Modifique bits.c para que acepte valores de 0 a 255 y muestre los ocho bits, separando los dos nibbles con un espacio (por ejemplo 1100 1010).
  4. Escriba un programa que lea un entero y, usando máscaras, imprima: el valor con el bit 2 encendido, con el bit 5 apagado y con el bit 0 invertido. Muestre los tres resultados en hexadecimal con %X.
  5. Prediga en papel el valor de cada expresión y luego verifíquelo con un programa: 7 / 2, 7 % 2, 7.0 / 2, -7 / 2, 1 << 5, 0xF0 >> 4, ~0, !5, 5 & 3, 5 && 3.
  6. Escriba un programa que lea dos valores de 0 a 255 y muestre el resultado de &, |, ^ entre ellos, tanto en decimal como en hexadecimal. Verifique a mano, en binario, que los resultados sean correctos.
  7. Un sensor entrega un byte donde los 4 bits altos son la temperatura y los 4 bits bajos un código de error. Escriba un programa que lea el byte y separe ambos campos.
