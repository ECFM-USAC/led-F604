Por qué un bucle

El programa bits.c de la clase de operadores extraía cuatro bits con cuatro líneas casi idénticas. Para ocho bits harían falta ocho, y para 32 el programa sería absurdo. Un bucle (o ciclo) ejecuta un bloque repetidamente mientras una condición se cumpla, y es lo que convierte un programa de longitud fija en un algoritmo.

Todo bucle tiene tres piezas, aunque no siempre estén escritas juntas:

Inicialización

El estado antes de la primera vuelta: i = 0, fahr = LOWER.

Condición

Se evalúa antes de cada vuelta. Mientras sea distinta de cero, el cuerpo se ejecuta otra vez.

Actualización

El cambio que, vuelta a vuelta, acerca la condición a ser falsa. Si falta, el bucle no termina.

El ciclo while

while evalúa la condición antes de cada vuelta. Si la condición es falsa desde el principio, el cuerpo no se ejecuta ni una vez.

while (condicion) {
    /* cuerpo: se repite mientras condicion sea distinta de cero */
}

El ejemplo clásico del K&R imprime una tabla de temperaturas en Fahrenheit con su equivalente en Celsius, según C = (5/9)(F − 32):

/* temp_while.c -- tabla Fahrenheit-Celsius con while */
#include <stdio.h>

int main(void)
{
    int   lower = 0, upper = 300, step = 20;
    float fahr, celsius;

    fahr = lower;                        /* inicializacion */

    printf(" F     C\n");
    printf("----------\n");

    while (fahr <= upper) {              /* condicion      */
        celsius = (5.0 / 9.0) * (fahr - 32.0);
        printf("%4.0f %6.1f\n", fahr, celsius);
        fahr = fahr + step;              /* actualizacion  */
    }

    return 0;
}

Su salida, que ya es una tabla presentable:

 F     C
----------
   0  -17.8
  20   -6.7
  40    4.4
  60   15.6
  ...
 300  148.9

Las constantes se escriben 5.0 y 9.0, no 5 y 9: con enteros, 5/9 vale 0 y toda la tabla saldría en cero. Es la trampa de la división entera de la clase anterior, en su forma más famosa.

El ciclo for

for es el mismo bucle con las tres piezas reunidas en una sola línea, lo que hace evidente de un vistazo cuántas vueltas dará:

for (inicializacion; condicion; actualizacion) {
    /* cuerpo */
}

La misma tabla, ahora con for y con un contador entero:

/* temp_for.c -- tabla Fahrenheit-Celsius con for */
#include <stdio.h>

int main(void)
{
    int fahr;

    for (fahr = 0; fahr <= 300; fahr = fahr + 20) {
        printf("%4d %6.1f\n", fahr, (5.0 / 9.0) * (fahr - 32));
    }

    return 0;
}

Desde C99 la variable de control puede declararse dentro del propio for, y entonces solo existe dentro del bucle. Es la forma preferible, porque impide usarla por error después:

for (int i = 0; i < 8; i++) {
    printf("bit %d\n", i);
}
/* aqui i ya no existe */

Use for cuando...

...el número de vueltas se conoce o depende de un contador: recorrer bits, filas de una tabla, elementos de un arreglo.

Use while cuando...

...la repetición depende de un evento y no de un contador: leer hasta fin de archivo, repetir hasta que el usuario acierte.

El ciclo do ... while

La tercera variante evalúa la condición al final, por lo que el cuerpo se ejecuta al menos una vez. Nótese el punto y coma final, que es obligatorio.

do {
    /* cuerpo */
} while (condicion);

Es la estructura natural para validar entrada: hay que pedir el dato antes de poder juzgarlo.

int n;

do {
    printf("Ingrese un valor de 0 a 15: ");
    scanf("%d", &n);
} while (n < 0 || n > 15);

printf("valor aceptado: %d\n", n);

En la práctica do...while es el menos usado de los tres. Si duda, use while o for: un bucle que siempre debe ejecutarse una vez es menos frecuente de lo que parece.

break y continue

Dos sentencias alteran el flujo normal de un bucle, y conviene no confundirlas:

break

Abandona el bucle de inmediato y continúa después de la llave de cierre. En un switch, termina el switch.

for (int i = 0; i < 100; i++) {
    if (dato[i] < 0) {
        break;      /* sale del bucle */
    }
}

continue

Salta el resto del cuerpo y pasa a la siguiente vuelta. En un for, la actualización sí se ejecuta.

for (int i = 0; i < 100; i++) {
    if (i % 2 != 0) {
        continue;   /* ignora los impares */
    }
    printf("%d ", i);
}

Ambas afectan únicamente al bucle más interno que las contiene. En bucles anidados, un break en el bucle interior no sale del exterior.

Bucles anidados: la tabla de verdad completa

Un bucle dentro de otro recorre todas las combinaciones de dos variables. Con eso, la tabla de verdad que en la primera clase se escribió a mano con cuatro printf ahora se calcula:

/* tabla_and.c -- tabla de verdad generada, no escrita a mano */
#include <stdio.h>

int main(void)
{
    printf(" A | B | AND | OR | XOR\n");
    printf("---+---+-----+----+-----\n");

    for (int a = 0; a <= 1; a++) {
        for (int b = 0; b <= 1; b++) {
            printf(" %d | %d |  %d  | %d  |  %d\n",
                   a, b, a & b, a | b, a ^ b);
        }
    }

    return 0;
}

El bucle exterior fija A y el interior recorre B completo: las filas salen en el mismo orden que en la tabla de verdad del libro (00, 01, 10, 11). Para tres variables se agrega un tercer nivel, y así se verifica cualquier función booleana de la Unidad 2:

/* verifica.c -- tabla de verdad de F = A.B + C' */
#include <stdio.h>

int main(void)
{
    printf(" A B C | F\n");
    printf("-------+---\n");

    for (int a = 0; a <= 1; a++) {
        for (int b = 0; b <= 1; b++) {
            for (int c = 0; c <= 1; c++) {
                int f = (a & b) | (!c);
                printf(" %d %d %d | %d\n", a, b, c, f);
            }
        }
    }

    return 0;
}

Este programa es una herramienta de estudio, no solo un ejercicio: permite comprobar en segundos si una simplificación por álgebra booleana o por mapa de Karnaugh produce la misma tabla de verdad que la expresión original.

Ejemplo: de decimal a binario

Con un bucle, imprimir los ocho bits de un número deja de ser repetir ocho líneas. Se recorre de la posición 7 a la 0 y se extrae cada bit con el desplazamiento y la máscara ya conocidos:

/* a_binario.c -- imprime un byte en binario */
#include <stdio.h>

int main(void)
{
    int n;

    printf("Ingrese un valor de 0 a 255: ");
    scanf("%d", &n);

    printf("%3d = ", n);
    for (int i = 7; i >= 0; i--) {
        printf("%d", (n >> i) & 1);
        if (i == 4) {
            printf(" ");          /* separa los dos nibbles */
        }
    }
    printf(" (0x%02X)\n", n);

    return 0;
}

El método de divisiones sucesivas de la Unidad 1 también se programa con un bucle, pero produce los bits en orden inverso (primero el menos significativo):

int t = n;
while (t > 0) {
    printf("%d", t % 2);   /* bit menos significativo primero */
    t = t / 2;
}

Para imprimirlos en el orden correcto habría que guardarlos y recorrerlos al revés; eso necesita un arreglo, que es el tema de la clase 6. Por ahora, el recorrido con >> resuelve el problema sin almacenar nada.

Ejemplo: contar los bits en 1

Contar cuántos bits valen 1 —el peso de la palabra, que determina por ejemplo el bit de paridad de la Unidad 1— es un bucle de cuatro líneas:

/* peso.c -- cuenta bits en 1 y calcula la paridad */
#include <stdio.h>

int main(void)
{
    int n, cuenta = 0;

    printf("Ingrese un valor de 0 a 255: ");
    scanf("%d", &n);

    for (int t = n; t != 0; t >>= 1) {
        cuenta += t & 1;        /* suma 1 si el bit actual esta en 1 */
    }

    printf("%d tiene %d bits en 1\n", n, cuenta);
    printf("paridad par: bit de paridad = %d\n", cuenta & 1);

    return 0;
}

El bucle termina solo: cada t >>= 1 acerca a t a cero, y cuando no quedan bits en 1 la condición es falsa. Es un buen ejemplo de bucle cuyo número de vueltas depende del dato, no de un contador fijo.

Entrada y salida de caracteres

La entrada/salida no es parte del lenguaje C: es parte de la biblioteca estándar. El modelo más simple trata la entrada como un flujo de caracteres, leído de a uno:

FunciónQué hace
c = getchar();Lee el siguiente carácter del flujo de entrada y lo devuelve; al terminar la entrada devuelve EOF.
putchar(c);Escribe un carácter en la salida.
EOFConstante definida en stdio.h (normalmente −1) que marca el final del flujo. No la redefina.

El bucle que copia la entrada a la salida es uno de los idiomas más reconocibles de C:

/* copia.c -- copia la entrada a la salida, caracter por caracter */
#include <stdio.h>

int main(void)
{
    int c;                       /* int, NO char: debe poder valer EOF */

    while ((c = getchar()) != EOF) {
        putchar(c);
    }

    return 0;
}

La condición merece leerse despacio: (c = getchar()) != EOF hace tres cosas en orden —llama a getchar, guarda el resultado en c y compara ese resultado con EOF—. Los paréntesis interiores son obligatorios: sin ellos, c = getchar() != EOF guardaría en c el valor 0 o 1 de la comparación.

Para terminar la entrada desde el teclado se envía el fin de archivo: Ctrl‑D en Linux y macOS, Ctrl‑Z seguido de Enter en Windows. También puede alimentar el programa desde un archivo: ./copia < texto.txt.

Ejemplo: contar líneas, palabras y caracteres

Este programa, tomado del K&R, reúne casi todo lo visto hasta aquí: un bucle de lectura, condicionales encadenados, operadores lógicos y una variable de estado que recuerda si se viene leyendo una palabra. Esa variable de estado es la misma idea que un flip-flop en la Unidad 4: la salida depende de la entrada y de lo que ocurrió antes.

/* contar.c -- cuenta lineas, palabras y caracteres de la entrada */
#include <stdio.h>

#define DENTRO 1    /* estamos dentro de una palabra */
#define FUERA  0    /* estamos fuera de una palabra  */

int main(void)
{
    int c;
    int nl = 0, nw = 0, nc = 0;     /* lineas, palabras, caracteres */
    int estado = FUERA;

    while ((c = getchar()) != EOF) {
        nc++;

        if (c == '\n') {
            nl++;
        }

        if (c == ' ' || c == '\n' || c == '\t') {
            estado = FUERA;
        } else if (estado == FUERA) {
            estado = DENTRO;
            nw++;                   /* cuenta la palabra al ENTRAR */
        }
    }

    printf("lineas: %d  palabras: %d  caracteres: %d\n", nl, nw, nc);
    return 0;
}

La clave está en cuándo se incrementa nw: no al ver una letra, sino en la transición de FUERA a DENTRO. Contar en cada letra daría el número de caracteres; contar en cada espacio fallaría con espacios consecutivos. El cambio de estado es el evento correcto, igual que en un detector de flanco.

Bucles infinitos

Un bucle sin condición de salida se escribe deliberadamente así:

while (1) {
    /* ... */
}

for (;;) {
    /* ... */
}

Lejos de ser un error, es la estructura normal de un programa empotrado: un microcontrolador arranca, configura sus puertos y entra en un lazo que no termina nunca, leyendo entradas y actualizando salidas.

int main(void)
{
    /* configuracion inicial del hardware */

    for (;;) {
        /* leer entradas, procesar, escribir salidas */
    }
}

El bucle infinito accidental es otra cosa: casi siempre se debe a una condición que nunca cambia porque falta la actualización. Si su programa se cuelga, interrúmpalo con Ctrl‑C y revise qué variable debía modificarse dentro del cuerpo.

ErrorSe ve asíQué ocurre
Punto y coma tras el forfor (i = 0; i < 10; i++);El cuerpo es el ; vacío: el bloque siguiente se ejecuta una sola vez, con i ya en 10.
Error por uno (off-by-one)for (i = 0; i <= 8; i++) sobre 8 bitsDa nueve vueltas. Con índices desde 0, la condición correcta es i < 8.
Falta la actualizaciónwhile (n > 0) { suma += n; }n nunca cambia: bucle infinito.
Modificar el contador dentro del cuerpofor (i = 0; i < n; i++) { ... i++; ... }Avanza de dos en dos sin que se note al leer el encabezado.

Comparar flotantes como contadorfor (x = 0.0; x != 1.0; x += 0.1)La suma acumula error y x nunca vale exactamente 1.0. Use < o un contador entero.

Ejercicios propuestos

  1. Modifique temp_for.c para que imprima la tabla al revés, de 300 a 0 grados Fahrenheit, y agregue un encabezado a las columnas.
  2. Escriba un programa que genere la tabla de conversión inversa, de Celsius a Fahrenheit, de −40 a 100 grados en pasos de 10.
  3. Escriba un programa que imprima la tabla de verdad completa de un sumador completo (entradas A, B, Cin; salidas S y Cout) usando tres bucles anidados y las expresiones S = A ^ B ^ Cin y Cout = (A & B) | (Cin & (A ^ B)). Compárela con la tabla del libro.
  4. Escriba un programa que imprima, para los valores de 0 a 15, una tabla con cuatro columnas: decimal, binario de 4 bits, hexadecimal y código Gray. Recuerde que el código Gray se obtiene con n ^ (n >> 1).
  5. Escriba un programa que lea caracteres hasta EOF y cuente cuántos son dígitos, cuántos espacios en blanco y cuántos son otra cosa.
  6. Escriba un programa que copie su entrada a la salida reemplazando toda secuencia de uno o más espacios por un solo espacio. Pruébelo con ./programa < archivo.txt.
  7. Escriba un programa que imprima todas las líneas de la entrada que tengan más de 80 caracteres.
  8. Escriba un programa que, para cada número de 0 a 255, cuente sus bits en 1 e imprima únicamente los que tengan paridad impar.
  9. Escriba un programa que simule un contador binario de 4 bits: imprima los estados de 0000 a 1111 en orden, uno por línea, indicando en cuáles cambia el bit más significativo.
